# Schießbude

Die Schüler:innen werden zuerst zu Spieletester:innen und anschließend können sie selbst kreativ werden und das Spiel verbessern.

## Ablauf

Bei diesem Projekt testen die Schüler:innen zuerst ein vorgefertigtes Spiel, um sich mit den Mechaniken vertraut zu machen. Anschließend erhalten sie die Aufgabe, das Spiel zu verbessern oder zu erweitern, indem sie neue Funktionen hinzufügen oder das Design anpassen.
