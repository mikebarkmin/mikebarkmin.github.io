# Stift-Name

Ein Namensring für Stifte: Der Name wird als erhabener Text auf einen Ring extrudiert, der auf den Stift gesteckt wird. So verschwinden Stifte nicht mehr in fremden Mäppchen. Den Namen kannst du im Modell einfach anpassen.
