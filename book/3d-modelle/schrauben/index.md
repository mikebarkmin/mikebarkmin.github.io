# Schrauben

Verlängerung für M8-Schrauben: Ein Zylinder mit durchgehendem M8-Innengewinde zum Aufschrauben, eine separate Gabel zum Aufstecken auf einen Balken und eine passende M8-Gewindestange ohne Kopf. Die Gabel nimmt die Biebelast vom Gewinde und wird liegend gedruckt, sodass die Schichten entlang der Arme laufen.
