# mikebarkmin.github.io

Personal website of Mike Barkmin, built with [Hyperbook](https://hyperbook.openpatch.org/).

🌐 **Live site:** [www.barkmin.eu](https://www.barkmin.eu)

## Content

- 📝 Blog posts
- 📚 Publications
- 🎤 Talks (Vorträge)
- 🛠️ Tools
- 📖 Materials
- 💡 Today I Learned (TIL)

## Development

```bash
# Start development server
npx hyperbook dev

# Build for production
npx hyperbook build
```
